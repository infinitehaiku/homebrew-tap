# Infinite Haiku Homebrew tap

```sh
brew install infinitehaiku/tap/ih-mcp
```

`ih-mcp` is the Infinite Haiku agent door: a read-only MCP server on your
own machine. Set it up with the guide at
https://infinitehaiku.com/docs/connect-ai-agent.

The formulae are generated from each release; LICENSE covers the programs
they install.
